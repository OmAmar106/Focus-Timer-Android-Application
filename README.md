# ⏳ Focus Timer App

**Focus Timer** is a productivity application designed to help you stay concentrated and avoid distractions.  
While the timer is running:
- The **back button** is **disabled** to prevent accidental exits.
- **Do Not Disturb (DND)** mode is **automatically turned on** to block notifications.

Stay in the zone and get more done!

---

## ✨ Features

- ⏰ Simple and customizable focus timer
- 🚫 Disables **back button** during active focus sessions
- 🔕 Automatically activates **DND (Do Not Disturb)** mode to minimize distractions
- 📈 Helps build deep work habits and maintain concentration
- 📜 **Session history** saved using **Firebase** for tracking your focus progress
- 🎵 View and control the **music currently playing** directly from the app
- 🌗 Supports both **Dark Mode** and **Light Mode** for comfortable viewing
- ⏰ **Alarm notification** when the timer finishes to alert you that the session is complete

## 🚀 Usage

1. Set your desired focus duration.
2. Start the timer — back button will be disabled and DND will turn on.
3. Concentrate on your task without interruptions.
4. Once the timer ends, DND is automatically turned off and normal device behavior resumes.
